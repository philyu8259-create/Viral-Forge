Support

This page summarizes common ViralForge troubleshooting steps.

Restore Purchases

Open ViralForge, go to Settings or the Pro tab, then tap Restore Purchases. Make sure you are signed in with the same Apple ID used to purchase the subscription.

Generation Issues

If copy generation or AI background generation fails, check your network connection and try again. Free copy generation is limited to 3 generations per day and resets daily. Free AI background generation includes 3 total uses and does not reset.

Data Deletion

Local-only data can be removed by deleting the app from the device or using Clear Local Workspace Data in App Settings. Generated projects can be removed from the Projects screen.
