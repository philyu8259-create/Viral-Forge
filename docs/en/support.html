Restore Purchases

Open ViralForge, go to Settings or the Pro tab, then tap Restore Purchases. Make sure you are signed in with the same Apple ID used to purchase the subscription.

Generation Issues

If copy generation or AI background generation fails, check your network connection and try again. If the issue continues, email us with the time of the issue, the selected platform, whether a product reference image was used, and the steps you took.

Data Deletion

For backend-synced data deletion, use the data deletion email button in App Settings. Local-only data can be removed by deleting the app from the device.
